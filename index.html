Method

Each company is reduced to a single evolving family line. When a new flagship or representative upgrade appears, that release point becomes the next node on the line.

Data caveat

This version uses a curated normalized trajectory dataset so each family line stays continuous from an early public version to later representative upgrades. Scores should be read as modality-specific comparison indices, not mixed across tabs.
